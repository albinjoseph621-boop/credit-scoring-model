Credit Scoring Model using Machine Learning

Overview

This project implements a Credit Scoring Model using Machine Learning techniques to predict whether a loan applicant is a good or bad credit risk. The model is trained using the German Credit Dataset and helps financial institutions assess loan applicants based on historical credit information.

Problem Statement

Banks and financial institutions need to evaluate the creditworthiness of loan applicants before approving loans. Manual evaluation can be time-consuming and prone to errors. This project uses Machine Learning algorithms to automate credit risk prediction and support better decision-making.

Dataset

* Dataset: German Credit Dataset
* Source: UCI Machine Learning Repository
* Records: 1000 applicants
* Features include:
    * Age
    * Credit Amount
    * Loan Duration
    * Employment Status
    * Savings Account Information
    * Housing Status
    * Other Financial Attributes

Results

The trained model successfully predicts whether a loan applicant represents a good or bad credit risk. Performance comparison between Logistic Regression and Random Forest helps identify the better-performing model.
